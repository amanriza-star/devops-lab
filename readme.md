# DevOps Lab

Учебный стенд для изучения DevOps.

## check_nginx.sh

Скрипт проверяет, работает ли nginx, и перезапускает его, если он упал.
Результат проверки записывается в лог.

### Как использовать

Запуск вручную:
```
sudo ./check_nginx.sh
```

Автоматический запуск каждые 5 минут через cron (`sudo crontab -e`):
```
*/5 * * * * /home/vboxuser/scripts/check_nginx.sh
```
